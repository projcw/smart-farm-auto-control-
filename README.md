# Smart Farm Auto Control System

Raspberry Pi와 Python을 이용해 온습도 센서 데이터를 기반으로
워터펌프를 자동 제어하는 스마트팜 시스템입니다.

## 사용 환경
- Raspberry Pi (Ubuntu OS)
- Python 3

## 사용 라이브러리
- Adafruit_DHT
- RPi.GPIO

## 하드웨어 구성
- DHT22 온습도 센서
- 토양 습도 센서
- 워터펌프 + 릴레이 모듈
- 플로트 스위치 (수위 감지)
- 브레드보드

## 동작 방식
- 온도 28°C 초과 또는 습도 45% 미만일 때 워터펌프 자동 작동
- 플로트 스위치로 수위 감지, 물 부족 시 펌프 보호
- 2분마다 센서 값 측정 및 로그 파일 기록

## 오류 해결
구현 중 센서 값이 정상임에도 펌프가 동작하지 않는 오류 발생.
코드 로직 → 센서 설정 → 회로 연결 순으로 단계적으로 점검한 결과
브레드보드 접촉 불량이 원인임을 확인하고 해결.
